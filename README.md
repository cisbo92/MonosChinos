# Kino Plugin - MonosChinos Anime

Este es un plugin para la aplicación **Kino** que permite indexar y reproducir el catálogo de anime disponible en MonosChinos de forma directa y optimizada.

## Características
- 📺 Catálogo completo de series de anime recientes.
- 🔍 Buscador integrado.
- 📥 Soporte experimental para descargas directas en la app.

## Instalación en Kino
1. Abre la app **Kino** en tu celular o televisor.
2. Ve a **Ajustes** ➔ **Plugins** ➔ **Agregar plugin** (o toca el botón `+`).
3. Escribe la ruta de este repositorio en formato: https://github.com/cisbo92/MonosChinos.git
4. Toca en **Agregar** e instala el complemento.
